# Sitemap

MediConnect includes exactly three main pages, as required for Week 1.

1. Home
   - Hero section
   - Trust indicators
   - Services overview
   - Patient journey
   - CTA block

2. Find Care
   - Search and filter controls
   - Specialty categories
   - Provider cards
   - Clinic highlights
   - Helpful resources section

3. Appointments
   - Upcoming appointment summary
   - Booking steps
   - Available time slots
   - Visit reminders
   - Support information

## Navigation structure
- Home page links to Find Care and Appointments
- Find Care links back to Home and Appointments
- Appointments links back to Home and Find Care
- Each page includes a consistent header and footer navigation
