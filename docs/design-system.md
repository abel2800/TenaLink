# Design System and Color Tokens

## Design direction
MediConnect adopts a premium, calming healthcare visual identity built around white space, emerald green accents, and crisp sans-serif typography. The system emphasizes clarity and trust while remaining modern and accessible.

## Color tokens
- Emerald 50: #ECFDF5
- Emerald 100: #D1FAE5
- Emerald 500: #10B981
- Emerald 600: #059669
- Emerald 700: #047857
- Slate 50: #F8FAFC
- Slate 100: #F1F5F9
- Slate 700: #334155
- Slate 900: #0F172A
- White: #FFFFFF

## Typography
- Headings: "Segoe UI", "Inter", sans-serif
- Body: "Segoe UI", "Inter", sans-serif
- Font weight emphasis: 500, 600, 700

## Spacing scale
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px
- xxl: 48px

## Layout rules
- Twelve-column desktop grid with comfortable margins
- Single-column mobile stacking order
- Cards with rounded corners and subtle shadows
- Generous spacing between major sections
- High contrast for accessibility

## Component style
- Buttons: rounded full-width or pill-shaped depending on context
- Cards: white background with soft border and shadow
- Inputs: white surfaces with emerald border focus ring
- Badges: emerald accent backgrounds for status or category labeling
